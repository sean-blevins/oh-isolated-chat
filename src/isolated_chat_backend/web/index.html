Isolated Docker Chat

An isolated conversation runs in its own container: Canvas cannot fork it, and new conversations start from an empty runtime directory. This page is the host side of that gap. Promote merges a conversation's memory into the durable store that new conversations are seeded from, as a line union: it only adds lines the durable store does not already have, and never rewrites the conversation's copy. Fork copies a conversation's full history and state into a new conversation, on the source's own LLM profile or on another one you pick per row.

Isolated Docker Chat

An isolated conversation runs in its own container: Canvas cannot fork it, and new conversations start from an empty runtime directory. This page is the host side of that gap. A new conversation is seeded from the durable store — the plugin carrying the handover, spawn, done and memory skills, plus the memory lines keyed to the agent profile it launches on. As a conversation runs, its memory is captured automatically back into that store, as a line union: it only adds lines the store does not already have, and never rewrites the conversation's copy. There is no button to press. Fork copies a conversation's full history and state into a new conversation, on the source's own LLM profile or on another one you pick per row. Hand over starts a fresh conversation seeded with the conversation's handover.md and no carried context, linking back so the chain can be followed. Open jumps to the conversation in Canvas and Delete removes it there and drops its local runtime directory; durable memory is kept.

New conversation

Starts a conversation this app owns: it seeds the plugin into the conversation's runtime directory before creating it, so the container's first run already has it, and seeds the durable memory keyed to the chosen agent profile. The plugin carries a handover skill and a hook that logs to .openhands/handover/hook.log, counts runs, and detects a handover request, plus a spawn skill: the agent writes a request to .openhands/spawn/ and the backend's watcher starts a new top-level conversation for it, running the task as an OpenHands goal; when the worker finishes, the host posts its result back into the spawning conversation. No page needs to be open. A done skill lets a worker leave its own completion summary, and a memory skill tells the agent how and when to write durable memory. The conversation launches on the chosen agent profile, with the chosen LLM profile overriding the profile's own — the same path Canvas's own launcher uses, so the credentials are resolved by the Agent Server and never handled here.

What new conversations are seeded from. Lines are captured automatically from every conversation as it writes them; conversations keep their own copies. Edit or delete a line to curate it — a change also applies to the conversation copies that carry it, so the next capture does not put it back.
